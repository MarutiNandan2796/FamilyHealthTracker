# 🏥 Family Health Tracker

A simple web-based application to help families track health records, appointments, medications, and vitals for each member using HTML, CSS, JavaScript, and PHP with MySQL.

---

## 📌 Features

- 👤 User authentication (Login & Registration)
- 👪 Add and manage family members
- 🩺 Record health data: weight, blood pressure, sugar levels, etc.
- 💊 Medication tracker with reminders
- 📅 Appointment scheduler
- 📈 View health history with charts
- 📧 Email alerts for upcoming appointments (optional)

---

## 🔧 Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP
- **Database**: MySQL
- **Libraries/Tools**: Chart.js (for graphs), Bootstrap (for UI)
